# 0055 — Публичный состав исходников и исследовательских результатов

## Статус: accepted

## Контекст

Исследовательский проект должен собираться из опубликованного исходного
кода. Читателю нужны русское описание компонентов, границы реализации и
результаты, связанные с конкретными версиями кода.

## Рассмотренные варианты

- Публикация всего рабочего репозитория.
- Отдельный состав исходников, тестов, документации и проверенных результатов.
- Хранение всех результатов в отдельной ветке без указателя в основной ветке.

## Решение

Публичный состав формируется отдельно и имеет собственную историю.
Сообщения коммитов пишутся на английском в формате Conventional Commits.
Изменения группируются по техническому смыслу. Публикуются только явно
выбранные ветки и теги; массовая отправка ссылок Git не используется.

Документация для читателя пишется на русском. Реализованные возможности
отделяются от планов. Каталог `docs/experiments/` содержит указатель,
проверенные отчёты, сценарии и исходные наблюдения. Крупные данные могут
размещаться отдельно, с контрольными суммами и привязкой к версии кода.

Исторические измерения сохраняют исходные наблюдения и обозначение версии,
на которой были получены. Им нельзя присваивать новую версию кода без
проверки соответствия. Отбор для публикации не означает повторного измерения.

## Последствия

Каждый состав проверяется по списку файлов, зависимостям сборки, ссылкам
документации и тестам. Зависимости фиксируются версиями и ревизиями.
Проверка с локальным кэшем зависимостей отличается от проверки получения
зависимостей на чистой машине; результаты этих проверок указываются отдельно.
