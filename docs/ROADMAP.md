# План исследования

| Этап | Состояние | Цель |
| --- | --- | --- |
| Основа сборки и IPC | Реализована | Согласованный запуск C++ и Go |
| Инструментация и мутационный цикл | Реализованы | Покрытие, корпус и обнаружение сбоев на фикстурах |
| I2S+SMT | Текущий этап; не закрыт | Измерить домены полезности и цену гибридного пути |
| Продуктовый LLM-бэкенд | План | Проверяемые подсказки решателю, полная отключаемость |
| Управление потоками | План | Воспроизводимое исследование расписаний |
| Собственный sanitizer | План | Детектирование ошибок памяти и гонок |
| Интеграция и оценка | План | Проверка пригодности на реальных целях |

Для закрытия текущего этапа нужны сравнительные измерения на глубоких
magic-number ветках, сохранение обнаружения ошибок на мутационных фикстурах
и итоговый отчёт с метриками и ограничениями. Реализованный MVP и отдельные
отрицательные результаты не заменяют эти критерии.

Полное символьное исполнение исключено из текущего охвата. Следующий этап
не начинается автоматически при появлении нового каталога или теста.
