# ПРАВИЛА, ВЫПИСАННЫЕ ДО ЗАМЕРА:
#  R1 отбрасывание прогрева: НЕ применяется. Публикуются ВСЕ значения,
#     медиана считается по всем без исключения, первый повтор не отбрасывается.
#  R2 время сборки: wall-clock полной команды компиляции+линковки, каждый
#     повтор в свежий выходной файл, секунды с тремя знаками.
#  R3 счёт проб, отдельно для каждой схемы (единицы РАЗНЫЕ, см. R4).
#     ВАЖНО: считается число ВСТАВЛЕННЫХ проб, а не выживших после -O2.
#     Счёт по релокациям в -O2-объектнике НЕПРИГОДЕН и не применяется: при
#     -O2 все статические функции цели инлайнятся в одну, адрес карты
#     материализуется один раз на функцию, и счётчик даёт 2 вместо тысяч.
#     Поэтому наши плечи считаются по LLVM IR, порождённому ТЕМ ЖЕ пассом
#     на -O0 (пасс регистрируется на PipelineStartEP, то есть вставка та же):
#     plain       — проб нет по построению; все счётчики печатаются, все нули;
#     ours        — число вхождений '@__mlfuzzz3_cov_map' в -O0 IR (одно на
#                   вставленную рёберную пробу — доступ к карте);
#     ours_branch — то же плюс число вызовов '@fuzzer_rt_log_branch_cmp'
#                   в -O0 IR (один на пробу канала); печатаются оба числа;
#     pcguard     — число guard-слов: СУММА размеров всех секций
#                   '__sancov_guards' в -O2 .o, делённая на 4 (секций две:
#                   основная и хвостовая, суммируются обе); рядом печатается
#                   число, которое сам afl-clang-fast сообщает в stderr;
#     classic     — число из stderr afl-clang-fast ('Instrumented N');
#     sancov      — сумма '__sancov_guards' / 4 по тому же правилу.
#  R4 несопоставимость: 'ours' считает РЁБРА (пара блоков), 'pcguard' и
#     'sancov' считают ГВАРДЫ (точки вставки на блок), 'classic' считает
#     точки вставки AFL. Пары (ours,pcguard), (ours,sancov), (ours,classic)
#     НЕСОПОСТАВИМЫ по абсолютному числу проб и помечаются как таковые.
#     Сопоставимы между собой только 'ours' и 'ours_branch'.
#  R5 цена канала значений ветвлений: ТОЛЬКО прямая разность наших двух
#     плеч (ours_branch минус ours), без участия чужих плеч.
#  R6 плечо, которое не собралось, печатается строкой status=failed с
#     текстом ошибки и НЕ выбрасывается; arms_built + arms_failed = 6.
#  R7 поправка Д3 (выписана до замера): grep по -O0 IR ловит ещё и строку
#     ОБЪЯВЛЕНИЯ глобала карты, поэтому публикуемое число проб равно
#     probes_cov_map_ir минус 1. Печатаются ОБА числа: сырое и поправленное.
#     Для чужих плеч поправка неприменима и печатается '-'.
#  R8 поправка Д1 (classic): число проб снимается ОТДЕЛЬНОЙ диагностической
#     сборкой с AFL_DEBUG=1 ВНЕ цикла замера времени — тайминги от этого не
#     зависят. Если и она молчит, печатается '-' и число не публикуется.
#  R9 поправка Д2 (sancov/pcguard): рядом с числом гвардов из -O2 объектника
#     печатается число из -O0 объектника той же командой. Расхождение -O0 и
#     -O2 РАЗДЕЛЯЕТ две гипотезы Д2: если на -O0 гвардов тысячи, схема
#     инструментирует то, что осталось ПОСЛЕ оптимизаций, и правило счёта
#     верно; если и на -O0 их единицы, дефект в конфигурации плеча.
