# Вклад I2S+SMT в покрытие синтетической цели

Историческое измерение сравнивает включённую руку I2S+SMT с `--no-concolic`.
В обоих вариантах используется тот же инструментированный бинарь цели,
мутации havoc, отключённые детерминированные стадии, одинаковые начальные
входы и зерно повтора. Десять повторов на вариант, 3000 исполнений на повтор.

## Наблюдение

Рука вызывалась 73 раза: 68 таймаутов решателя и 5 случаев отсутствия
привязки. Кандидатов не построено. Медиана покрытия — 19647 против 19645
ячеек; A₁₂=0.485, p после поправки Холма около 0.926. Значимого прироста
на этой цели при этом бюджете не обнаружено.

Ноль падений в обоих вариантах не позволяет сделать вывод о сравнительной
способности находить ошибки. Результат не переносится автоматически на
реальные цели, другой бюджет или текущую версию кода.

## Исходные данные и пересчёт

Сохранены [прогоны](raw-collect.txt) и [исходный анализ](raw-analysis.txt).
Оба файла неизменны относительно исторического архива. Команда пересчёта
из корня репозитория:

```sh
python3 docs/experiments/concolic-campaign-contribution/collect.py --phase analyze --execs 3000 --work /tmp/mlfuzzz3-analysis --raw docs/experiments/concolic-campaign-contribution/raw-collect.txt
```

Генератор цели и исходная калибровка потолка также включены, поскольку
анализатор использует их. Исторические ссылки на ревизии сохранены в
данных; соответствие текущего кода этим ревизиям не утверждается.
