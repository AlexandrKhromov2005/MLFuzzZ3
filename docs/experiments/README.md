# Эксперименты

В этот срез включены два исторических набора данных и проверка модульного переноса. Это не полный архив
исследования. Данные сохранены побайтно; новые кампании при подготовке
среза не запускались. Политика оценки — [EVALUATION.md](../EVALUATION.md).

| Вопрос | Отчёт | Материал |
| --- | --- | --- |
| Добавляет ли I2S+SMT покрытие? | [Вклад в кампанию](concolic-campaign-contribution/report.md) | N=10 на синтетической цели, одинаковый бюджет исполнений |
| Какова цена модульного переноса? | [Проверка композиции](modularity/report.md) | Матрица сборок, регрессии и изолированные микробенчмарки |
| Какова статическая цена инструментации? | [Стоимость сборки](instrumentation-cost/report.md) | Пять повторов, шесть вариантов инструментации |

Каждый каталог содержит исходные наблюдения и анализатор. Идентификатор
версии в исторических данных относится к исходному измерению; доступность
соответствующего полного среза кода ещё не обеспечена этой публикацией.
Пересчёт таблиц по сохранённым данным возможен отдельно от повторного
исполнения исторической версии. Нельзя считать эти наборы полностью
воспроизводимыми кампаниями до восстановления версий целей и окружения.

Новые результаты размещаются отдельным каталогом: русский отчёт, сценарий,
версия опубликованного кода, конфигурация, зерна, бюджеты, исходные данные
и команды анализа. Для внешнего архива обязательны устойчивая ссылка,
контрольная сумма и описание содержимого.
