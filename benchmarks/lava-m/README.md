# Цели LAVA-M

Каталог содержит сборочные сценарии внешней цели base64 из coreutils,
начальные входы и варианты инструментации для сравнений.
Полученные исходники и бинарные файлы находятся в `vendor/` и не входят
в репозиторий. Ревизии, источники и проверки архива определены скриптами
`build.sh`, `build_afl.sh` и `build_cov.sh`.

Это оснастка исследования. Наличие скриптов не означает завершённую
кампанию или подтверждённую сборку внешней цели в текущем окружении.
Исходники цели распространяются по собственной лицензии.
