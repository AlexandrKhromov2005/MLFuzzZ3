# Сравнительные цели Magma

Каталог содержит интеграцию с внешним набором Magma, сборку libpng/libtiff,
адаптеры фаззеров и сравнительные сценарии. Загружаемые исходники и продукты
сборки размещаются в `vendor/` и не входят в репозиторий.

Точки входа: `fetch_magma.sh`, `build.sh`, `build_tiff.sh`,
`comparative_run.py`, `comparative_run_tiff.py`. Аргументы сценариев
доступны через `--help`; число повторов и бюджет задаются явно.
При анализе используются нейтральное покрытие и оракулы набора.

Это исследовательская оснастка, а не включённые результаты кампании.
Для воспроизведения нужны указанные в скриптах внешние инструменты,
целевые исходники, их лицензии и окружение. Скачивание целей и новые
кампании при подготовке этого среза не выполнялись.
